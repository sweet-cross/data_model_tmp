# Variables

Variables represent quantities whose values are defined over one or more dimensions (such as region, technology, fuel, or year). The dimensions define the indexing of the variable, and the combination of their values forms the primary key for each observation. In addition to these key fields, variables also contain non-key fields such as the variable value and associated metadata.

CROSS distinguishes between two types of variables:

1. **[Assumptions](assumptions/index.md)**

    Variables used by the energy system models as input assumptions.
   
2. **[Results](results/index.md)**

    Output variables produced by the energys system models.
